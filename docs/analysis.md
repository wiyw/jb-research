# Version diff analysis

`analysis/27_0_1_24A446_vs_27_2_24B119/` compares iOS 27.0.1 (24A446) with
27.2 (24B119) for `iPhone17,3`. The report is generated by `ipsw diff` from the
two restore images:

```sh
ipsw diff \
  27.0.1/data/iPhone17,3_27.0.1_24A446_Restore.ipsw \
  27.2/data/iPhone17,3_27.2_24B119_Restore.ipsw \
  --output analysis/27_0_1_24A446_vs_27_2_24B119 \
  --markdown --fw
```

The download and extraction steps are in [firmware.md](firmware.md).

## Layout

```
README.md         Top-level summary: kernel, kexts, Mach-O, and dylib changes
KEXTS/            One Markdown report per kext
MACHOS/           One Markdown report per Mach-O image
  filesystem/       Filesystem images
  SystemOS/         SystemOS images
  AppOS/            AppOS images
  ExclaveOS/        ExclaveOS images
  filesystem.Updated.md
DYLIBS/           One Markdown report per dyld shared cache dylib
  Dylibs.Updated.md
```

The summary `README.md` groups entries as new, removed, or updated and links
to the per-file reports.

## Reading a report

Each per-file report contains:

- The image path
- Sections with the same size but changed content
- A code block with size deltas per section (`__TEXT.__text`,
  `__TEXT.__const`, `__DATA_CONST.__objc_classlist`, and so on)
- Version/build numbers where available

Example: `MACHOS/SystemOS/usr/lib/libramrod.dylib.md` shows the Mach-O version
moving from `3696.0.12.0.3` to `3696.40.14.0.1` and the resulting section size
changes.

## Scope

The diff covers:

- Kernel version and build timestamps
- Kext additions, removals, and updates
- Filesystem, SystemOS, AppOS, and ExclaveOS Mach-O images
- WebKit version and dyld shared cache dylib changes

The IPSWs themselves are not tracked; regenerate the reports with the command
above if you need a different build pair or additional `ipsw diff` options
(for example `--ent`, `--starts`, or `--strs`).
